# Dashboard Migration

Dashboard lama dari repo `instagram-tracker-dashboard` telah mulai dimigrasikan ke repo `Instagram-collector`.

## New location

```text
dashboard/
  index.html
  data.json
  vercel.json
```

## Source of truth

- `Follower History` <- SocialBlade stats
- `Engagement` <- Apify metrics
- `Content Breakdown` <- Apify content breakdown

## Migration status

- `index.html` copied into `dashboard/index.html`
- `vercel.json` copied into `dashboard/vercel.json`
- `dashboard/data.json` now generated by `scripts/export/build-dashboard-data.js`
- v2 dashboard schema is bridged into the old UI shape temporarily

## Important note

The current migrated `index.html` still uses a temporary compatibility bridge so the old UI can read the new v2 data schema.
The next recommended step is to simplify the UI to use the v2 schema natively.
